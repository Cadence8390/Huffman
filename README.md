**Huffman Coding in C++**

A C++ program that explores Huffman coding, a compression algorithm that uses character frequencies to construct a binary tree and assign variable-length binary codes to characters. This project demonstrates the use of data structures, binary trees, and algorithm design.

**Features**

Demonstrates the principles of Huffman coding

Uses C++ classes and data structures to organize program components

Works with binary trees as part of the Huffman coding process

Includes a test driver (main) to run the program

**How to Run (Visual Studio)**

Download the repository as a ZIP file from GitHub.

Extract the ZIP file to a convenient location.

Open the extracted folder and locate the .sln file.

Double-click the .sln file to open the project in Visual Studio.

In Visual Studio, select Debug → Start Without Debugging to build and run the program.
